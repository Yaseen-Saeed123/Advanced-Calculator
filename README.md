# Advanced-Calculator
This is an apply for the math module. View the README file to know more

# What Operations the calculator can do
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exponent
6. Remainder of division
7. Absolute Value
8. Square root (+ve & -ve)
9. Cube root
10. Conversion between degree and radian measures
11. Trigonometric functions
12. ArcTrigonometric functions
13. Some mathematical constants

# Constraints
1. Answer should be between 10<sup>-99</sup> and 10<sup>99</sup>
2. 0<sup>0</sup> causes a math error
3. Domain errors in trig and arctrig functions are handled
4. DivisionByZeroError is handled
